# Materials and Methods - Validation Prompts

```
Act as an experienced AACR journal editor and scientific reviewer.

I will provide the Materials and Methods section of my manuscript.

Please evaluate it against the following AACR expectations:

AACR Materials and Methods Requirements:

- The description of experimental methods should be sufficient for qualified investigators to reproduce the study.
- Procedures fully described in previous publications do not need to be repeated in detail, but appropriate references should be cited and any modifications clearly described.
- New procedures and substantially modified published procedures must be described in sufficient detail.
- If any experiments or analyses were outsourced to a core facility or external service provider, this should be explicitly stated, including the provider's name.
- Where applicable, methodological details performed by the provider should be included or an appropriate reference cited.
- Sources of all reagents, materials, instruments, software, and tools should be provided.
- Commercial products should include manufacturer name and catalog number where applicable.
- RRIDs (Research Resource Identifiers) should be included whenever appropriate.
- If statistical analyses were performed, a Statistical Analysis subsection should be present and sufficiently detailed.
- A Data Availability subsection should be included at the end of the Materials and Methods section.
- Methods should contain enough detail to support reproducibility and transparency.

Review Instructions:

1. Assess whether the Materials and Methods section provides sufficient information for reproducibility.

2. Evaluate whether:
   - Experimental procedures are adequately described.
   - Previously published methods are appropriately cited.
   - Modifications to published methods are clearly explained.
   - New methods are described in sufficient detail.
   - Reagents, antibodies, cell lines, animal models, software, databases, instruments, and other resources are properly identified.
   - Manufacturer information and catalog numbers are provided where appropriate.
   - RRIDs are included where appropriate.
   - Statistical methods are adequately described.
   - Data Availability information is included.
   - Outsourced work or core facility involvement is properly disclosed.
   - The overall structure meets AACR expectations.

3. Identify only substantive issues that may affect:
   - Reproducibility
   - Transparency
   - Scientific rigor
   - AACR compliance
   - Reader understanding

4. For each issue identified, provide:
   - Exact Sentence(s): Quote the exact sentence(s) from my Materials and Methods section that triggered the comment.
   - Problem: Explain the issue.
   - Why it matters: Explain the impact on reproducibility, transparency, or AACR compliance.
   - Suggested improvement: Describe what information should be added, clarified, removed, or reorganized. Do not rewrite the entire section.

5. Do NOT rewrite the manuscript.

6. Do NOT perform grammar correction, copyediting, or language polishing unless the issue affects scientific clarity or reproducibility.

7. If a required AACR element appears to be missing entirely, explicitly identify the missing element.

8. Only report issues that are genuinely important. Do not generate minor or speculative comments. If a section adequately satisfies AACR expectations, state that no revision is needed.

Present your feedback using the following format:
```
